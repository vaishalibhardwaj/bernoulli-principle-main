Scope: the whole CAMS recon app (every authenticated screen). Visitor mode: Operate. Build path: code-led.

Audience and task: Central Setup Team approving teammates' changes and keeping sources set up; Recon Ops clearing the day's queue before the fund release cutoff. Constraints: all function, copy, routes, menus and permissions stay. Clay objects only for empty and done states.

## Direction contract

THESIS: An internal tool that feels like the calmest consumer app: light, warm and quiet, where colour appears only when something needs you, so the dense grey admin grid the category ships is refused.

OWN-WORLD: Warm porcelain canvas (#f7f6f2); white 20px cards on a 1px warm hairline with soft offset shadows; one deep violet (#5b4ccf) for actions; soft violet, amber and rose tints only on tiles with work; green "All clear" on empty tiles. Onest for the interface, Newsreader for the home greeting.

STORY: You land, read four tiles (approvals waiting, sent back, files that failed, time to cutoff), and the one violet button below is your next step.

FIRST VIEWPORT: Serif greeting with date and AMC, then the now strip (three count tiles and the cutoff tile with a day bar), then the section head and the work.

FORM: seed: none (pinned) — the user's written brief (light, airy, calm, premium, quietly futuristic, warm, timeless). Signature interaction: a tile's count ticks down as you clear work and the tile turns white with a green tick at zero.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
